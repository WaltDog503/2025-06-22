2. Program Description
==================================================

This program reads a systems file and an access log file to track how often
each user accesses each ship system. The first line of each file contains a
count, and then the program reads exactly that many records.

The program creates a dynamic array of UserAccessList objects (one list per
system). Each list is a linked list of UserAccess entries that store
user,count data, and each list prints a formatted report with Top, Second,
and All user access totals and percentages.


==================================================
3. Algorithmic Design
==================================================

3a. Input Variables

Variable Name: argc
Data Type: integer
Description: Number of command-line arguments.

Variable Name: argv
Data Type: array of C-strings (char*[])
Description: Command-line argument values.

Variable Name: argv[1]
Data Type: C-string (char*)
Description: Access log filename provided by user.

Variable Name: argv[2]
Data Type: C-string (char*)
Description: Systems filename provided by user.

Variable Name: accessDataFile
Data Type: C-string (const char*)
Description: Access log filename taken from argv[1].

Variable Name: systemsFile
Data Type: C-string (const char*)
Description: Systems filename taken from argv[2].

Variable Name: systemsIn
Data Type: input file stream
Description: Stream used to read system names.

Variable Name: accessDataIn
Data Type: input file stream
Description: Stream used to read access records.

Variable Name: numSystems
Data Type: integer
Description: Number of systems from first line of systems file.

Variable Name: numEntries
Data Type: integer
Description: Number of records from first line of access file.

Variable Name: sys
Data Type: character array (char[RDBUFSIZE])
Description: Buffer for system name while reading.

Variable Name: who
Data Type: character array (char[RDBUFSIZE])
Description: Buffer for user name while reading.

Input data structures:
- allLists: dynamic array of UserAccessList pointers (UserAccessList**)
- each UserAccessList contains a linked list of UserNode objects


3b. Output Variables

Variable Name: Console report lines
Data Type: string output
Description: Formatted report output for each system.

Variable Name: mSystem
Data Type: dynamic C-string (char*)
Description: System name shown in report.

Variable Name: topUser
Data Type: C-string (const char*)
Description: User with the highest count.

Variable Name: secondUser
Data Type: C-string (const char*)
Description: User with second-highest count.

Variable Name: count
Data Type: integer
Description: Number of accesses for a user.

Variable Name: percent
Data Type: integer
Description: Percentage of total system accesses by user.


3c. Calculations

1) Total accesses for a system
   When an access record belongs to a system list:
   mTotalAccesses = mTotalAccesses + 1

2) Per-user count
   If user is already in linked list:
   userCount = userCount + 1
   Otherwise, create a new user entry with count = 1

3) Percentage for report output
   percent = (count * 100) / mTotalAccesses
   (integer division; truncated percentage)

4) Top and second top accessors
   Traverse the linked list and compare counts to track largest and second
   largest values.


3d. Logic (Pseudocode)

MAIN
  if argc is not 3
    print usage message
    return

  accessDataFile = argv[1]
  systemsFile = argv[2]

  open systems file
  read numSystems
  ignore newline

  allocate dynamic array allLists of size numSystems
  loop i from 0 to numSystems - 1
    read one system line into sys
    allLists[i] = new UserAccessList(sys)
  close systems file

  open access file
  read numEntries
  ignore newline

  loop i from 0 to numEntries - 1
    read system text into sys up to comma
    consume one space after comma
    read remaining user text into who

    loop j from 0 to numSystems - 1
      allLists[j]->addUser(sys, who)
  close access file

  loop j from 0 to numSystems - 1
    allLists[j]->printReport()

  loop j from 0 to numSystems - 1
    delete allLists[j]
  delete[] allLists
END MAIN


UserAccessList::addUser(systemName, user)
  if systemName does not match mSystem
    do nothing
  else
    mTotalAccesses++

    traverse linked list from mHead
      if current node user matches user
        increment count
      else
        if user not found after traversal
          create new UserAccess for user
          create new UserNode with that UserAccess
          append node to end of linked list


UserAccessList::printReport()
  print system header

  traverse linked list to determine top and second users
  print top and second names (or "(none)")

  print all user entries in list order:
    percent = (count * 100) / mTotalAccesses
    print user name, count, and percent
