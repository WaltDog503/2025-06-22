2. Program Description

In the box below, describe the purpose of the program. You must include a
detailed description with at least two complete sentences. Program
description:

This program reads two files: one file that lists the systems on a ship and
one file that lists access events in the form "system, user". It dynamically
creates one UserAccessList per system, tracks each user's access count with a
linked list, and prints a report for every system showing the top user, the
second-highest user(s), and all user counts with integer percentages.

3c. Calculations

What calculations do you need to do to transform inputs into outputs? List all
formulas needed, if applicable. If there are no calculations needed, state
there are no calculations for this algorithm. Formulae should reference the
variable names from step a and step b as applicable.

- Per-access system total increment:
  mTotalAccesses = mTotalAccesses + 1

- Per-user count increment for existing user:
  mCount = mCount + 1

- Percent for each user line in report:
  reportUserPercent = (reportUserCount * 100) / mTotalAccesses

- Safe zero-access case:
  if mTotalAccesses == 0 then reportUserPercent = 0

- Top and second logic:
  track topCount and secondCount while traversing linked list
  - if count > topCount: secondCount = topCount, topCount = count
  - else if count < topCount and count > secondCount: secondCount = count
  - any user with count == secondCount is printed in "Second" list

3d. Logic

Design the logic of your program using pseudocode (See note about pseudocode
below). Here is where you would use conditionals, loops or functions (if
applicable) and list the steps in transforming inputs into outputs. Walk
through your logic steps with the test data from the assignment document.

START main
  IF argc != 3
    print usage and stop
  ENDIF

  read systems file:
    read numSystems
    allocate allLists dynamic array of size numSystems
    loop numSystems times:
      read one system name
      create UserAccessList for that name
      store pointer in allLists

  read access log file:
    read numEntries
    loop numEntries times:
      parse one entry as sys and who
      for each list in allLists:
        call addUser(sys, who)

  for each list in allLists:
    call printReport()

  cleanup:
    delete each UserAccessList object
    delete dynamic array allLists
END main

UserAccessList::addUser(sys, who)
  if sys is null or who is null: do nothing
  if sys does not match mSystem: do nothing
  otherwise:
    increment mTotalAccesses
    traverse linked list to find user
    if found:
      increment that user's count
    else:
      create new UserAccess(who)
      append new UserNode to end of linked list

UserAccessList::printReport()
  traverse linked list once to compute:
    top user (highest count)
    secondCount (highest distinct count less than top)
  print:
    System line
    Top line
    Second line (all users with count == secondCount, comma-separated)
    All header
    each user line with count and integer percent

4. Pseudocode

(This section just describes pseudocode and is for your information only. You
don't need to include it in your algorithm.pdf document.)

The design should be written using pseudocode. That is, semi-formal English
statements that describe the algorithm. The purpose of using pseudocode is to
allow a developer to express the essential aspects of a program or algorithm
in a clear and unambiguous way without worrying about syntax or getting bogged
down in implementation details. In general, pseudocode does not require
specific syntax but needs to be clear enough to describe the algorithm. There
are various forms of "official" pseudocode but most developers use something
that feels intuitive. Using a very formal and strict pseudocode tends to
defeat the purpose of using pseudocode.

Here is an example of pseudocode for a small program to convert Celsius
degrees to Farenheit.

----

prompt user to input Celcius degrees
celDegrees = read user input

while celDegrees is not valid, repeat the first two steps

farDegrees = (celDegrees * 9/5) + 32

output farDegrees to user

prompt user to see if they want to do more calculations
if "yes" then go back to the beginning, else exit

----
